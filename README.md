## python-simple-server
Servidor simple hecho en Python para gestión de tareas.

## Diferencias entre los tipos de petición: GET, POST, PATCH y DELETE
- **GET**: Es utilizado para obtener recursos. En el caso del proyecto, se usa para obtener una tarea por su ID u obtener todo el listado de tareas.

- **POST**: Es utilizado para crear recursos. En el caso del proyecto, se usa para crear una nueva tarea.

- **PATCH**: Se utiliza para actualizar campos de recursos existentes. En el caso del proyecto, se usa para actualizar el título y/o estado de una tarea por su ID.

- **DELETE**: Se utiliza para eliminar recursos. En el caso del proyecto, se usa para eliminar una tarea por su ID.
